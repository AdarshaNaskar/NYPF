# New York Pizza Factory – Next-Generation Restaurant Website

A modern, AI-inspired restaurant website designed for **New York Pizza Factory**. This project reimagines the traditional restaurant website with a premium user experience, combining immersive animations, a cinematic hero section, and contemporary design principles to create a memorable first impression.

Built with a mobile-first approach, the website delivers a smooth, responsive, and visually engaging experience across all devices.

## ✨ Highlights

*  AI-inspired premium UI/UX
*  Cinematic animated hero section
*  Smooth scroll-based animations
*  Modern micro-interactions
*  Glassmorphism-inspired design elements
*  Clean and minimal visual hierarchy
*  Interactive restaurant menu
*  Story-driven About section
*  Customer testimonials
*  Contact & location section
*  Fully responsive across desktop, tablet, and mobile
*  Fast loading and optimized performance

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)

## 🎯 Project Vision

Rather than creating a conventional restaurant website, the goal was to build an experience that feels modern, interactive, and premium. Inspired by current frontend design trends, the project emphasizes animation, smooth navigation, and engaging visual storytelling while maintaining usability and performance.
